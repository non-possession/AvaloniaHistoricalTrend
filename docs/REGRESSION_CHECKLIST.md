# Regression Checklist

## Build

1. 运行 `dotnet build`
2. 预期结果：`0` 警告、`0` 错误

## Curves And Visibility

1. 启动程序
2. 观察 8 条曲线是否加载
3. 依次勾选/取消右侧变量卡的“显示”
4. 预期结果：对应曲线显示/隐藏，变量卡透明度同步变化

## Single/Dual Axis Layout

1. 点击顶部“单轴布局”
2. 预期结果：右侧 `Y2` 面板和右侧刷子隐藏，图表进入单轴比较模式
3. 点击顶部“双轴布局”
4. 预期结果：右侧 `Y2` 面板和右侧刷子恢复，图表进入双轴比较模式

## Y1/Y2 Axis Selection

1. 在双轴模式下切换 `Y1` 下拉框
2. 预期结果：左轴当前变量更新，其它曲线不因轴切换整体跳动
3. 在双轴模式下切换 `Y2` 下拉框
4. 预期结果：右轴当前变量更新，其它曲线保持既有状态

## Range And Brush Memory

1. 为一个变量设置自定义量程
2. 拖动上下刷子改变显示区间
3. 切换到其它变量后再切回
4. 预期结果：该变量的量程和刷子范围仍然保持

## Time Window

1. 拖动 X 轴左右刷子
2. 使用底部 `Zoom In / Zoom Out / 1 Day / 12 H / 30 Min` 等按钮
3. 使用左右平移按钮和跳转按钮
4. 预期结果：时间窗口正确变化，文本显示同步更新，最小跨度保护仍生效

## Crosshair

1. 鼠标移入主图绘图区
2. 预期结果：十字光标显示且不超出绘图区
3. 鼠标移出主图绘图区
4. 预期结果：十字光标隐藏

## Settings File

1. 修改 `trend-workbench.settings.json` 中的 `LayoutMode`
2. 重启程序
3. 预期结果：启动后布局模式与配置一致
4. 修改 `ShowLegend`
5. 重启程序
6. 预期结果：图例显示状态与配置一致
7. 修改 `DefaultVisibleDurationMinutes`
8. 重启程序
9. 预期结果：默认时间窗口跨度与配置一致
